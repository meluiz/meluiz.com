# meluiz.com

> Relishing the details. Fostering innovation. Achieving excellence.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/meluiz/meluiz.com)

## Stack

- **Front-end:** [NextJS](https://nextjs.org/)
- **Styling:** [TailwindCSS](https://tailwindcss.com/)
- **Linting and Formatting:** [Biome](https://biomejs.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## Running locally

1. Clone this repo:

```sh
$ https://github.com/meluiz/meluiz.com.git
```

2. Go to the project's folder:

```sh
$ cd meluiz.com
```

3. Install all dependencies:

```sh
$ bun install
```

4. Run locally:

```sh
$ bun dev
```
